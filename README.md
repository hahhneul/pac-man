# NEON MAZE

외부 라이브러리, 이미지, 사운드 없이 HTML Canvas와 자체 제작 도형으로 만든 미로 추격 아케이드 게임입니다.

## 실행 방법

1. `pac-man/index.html`을 Chrome, Edge, Firefox, Safari 같은 최신 브라우저에서 엽니다.
2. 별도 설치나 빌드 과정은 없습니다. VS Code의 Live Server를 사용해도 됩니다.
3. 시작 화면에서 `Enter`를 누르거나 `START` 버튼을 선택합니다.

## 조작법

- 이동: 방향키 또는 `W` `A` `S` `D`
- 일시정지 / 계속하기: `P`
- 새 게임으로 재시작: `R`
- 모바일: 화면 아래 방향 버튼 사용

작은 빛 점을 모두 모으면 다음 레벨로 이동합니다. 큰 에너지 볼을 얻은 동안에는 파란색으로 변한 추격자를 잡을 수 있으며, 중간에 나타나는 프리즘 과일은 추가 점수를 줍니다.
